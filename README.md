⚡ Electrician Contractor Management System

 Features

- Secure Login/Register
- Admin & Electrician Roles
- Task Management
- Material Management
- Profile Upload
- Reports & Dashboard
- Razorpay Payment Gateway
- Transaction History
- Salary Payment System
- Responsive Enterprise UI



 Technologies Used

- Python Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js
- Razorpay API



 Workflow

1. Admin Login
2. Create Jobs
3. Add Materials
4. Assign Tasks
5. Electrician Updates Status
6. Upload Reports
7. Client Makes Payment
8. Admin Pays Electrician
9. Transaction Saved




bash
pip install -r requirements.txt
python app.py
